iPXE web builder

Why

A Prebuilt binary web interface. Many users would prefer to be able to download prebuilt binary versions of iPXE, rather than building it from source.

Source

This is a maintenance fork of the original xbgmsharp/ipxe-buildweb project, kept moving while the upstream repository is quiet.
Comments, questions, suggestions and contributions are welcome.
Please fork and send a pull request, or open an issue on this fork.
